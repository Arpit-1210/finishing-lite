# Finishing Lite
Finishing-stage app (Factory OS). Supervisor app (`/`) and owner dashboard (`/owner.html`). Performance = value produced ÷ labour cost. No weight.
Setup: run `sql/finishing_setup.sql` once in Supabase; set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`; `npm install && npm run build`.
